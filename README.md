# 🎓 졸업요건 정리

홍익대 졸업요건을 정리하고, 내가 뭘 들어야 할지 한눈에 확인하는 웹사이트.

## 무엇을 할 수 있나요
- 전체 진행률 도넛 + 영역별 요건 카드(전공필수/전공선택/교양/자유선택)
- 과목을 학기(1-1~4-2)·영역별로 담으면 이수 학점 자동 계산
- 학기 로드맵으로 4년 수강 계획을 한눈에
- 과목명 입력 시 실제 교과과정 과목 자동완성(영역/학점/학기 자동 채움)
- 기록은 브라우저에 자동 저장 · 로그인 시 기기 간 동기화

## 로컬에서 열어보기
그냥 `index.html`을 브라우저로 열면 됩니다. 별도 설치 필요 없음.

## 다른 기기에서 이어서 작업하기
이 저장소는 GitHub에 올라가 있어요. 다른 노트북에서는:

```bash
git clone https://github.com/dear-my-sunday/hongik-graduation.git
```

수정한 뒤에는:

```bash
git add -A
git commit -m "수정 내용"
git push
```

브라우저만으로 편집하고 싶으면 https://claude.ai/code 에서 이 저장소를 열어도 됩니다.
